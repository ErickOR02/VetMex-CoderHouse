#  VetMex - Clínica Veterinaria

Sitio web desarrollado para una clínica veterinaria ficticia llamada **VetMex**, enfocada en el cuidado y bienestar de perros y gatos.

## Descripción

VetMex es una pagina web desarrollada como parte del curso de desarrollo web de CoderHouse.

El sitio tiene como objetivo presentar de manera clara y atractiva los servicios de una clínica veterinaria, su información institucional, galería, patrocinadores y medios de contacto.

## Páginas

El proyecto fue creado con las siguientes páginas:

- **Inicio** — Presentación de VetMex y sus servicios.
- **Contacto** — Formulario e información de contacto, correo y número telefonico.
- **Galería** — Galería de imágenes relacionadas con la veterinaria como pacientes atendidos y sucursales.
- **Nosotros** — Información sobre la clínica, nuestra misión y un poco sobre nuestros especialistas.
- **Sponsors** — Información sobre los patrocinadores del proyecto.

## Tecnologías utilizadas

- HTML5
- CSS3
- SCSS / Sass
- Bootstrap 5
- AOS
- Git
- GitHub

## Características

- Diseño responsive para diferentes tamaños de pantalla, telefonos, tabletas y computadoras de escritorio.
- HTML semántico.
- Arquitectura modular utilizando SCSS.
- Navegación entre diferentes páginas.
- Formulario de contacto (sin back-end).
- Animaciones mediante AOS.
- Componentes de Bootstrap.
- Organización de estilos mediante archivos parciales de Sass.
